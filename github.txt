GitHub - это крупнейший веб-сервис для хостинга IT-проектов и их совместной разработки, работающий на базе системы контроля версий Git.
Push - Отправляет локальные изменения (коммиты) из компьютера на GitHub.
Pull - Скачивает изменения с GitHub на компьютер



Контрольные вопросы
1.	Что такое удалённый репозиторий? 
Версия проекта, размещённая на GitHub, которая служит для обмена изменениями между разработчиками
2.	Чем отличается git push от git pull? 
git push отправляет локальные коммиты в удалённый репозиторий, а git pull забирает изменения из удалённого репозитория и объединяет их с текущей локальной веткой
3.	Что делает команда git clone? 
git clone создаёт локальную копию удалённого репозитория
4.	Что такое origin? 
origin - это стандартное имя, которое Git присваивает удалённому репозиторию, откуда был сделан клон
5.	Для чего нужна ветка на GitHub? 
Ветка на GitHub позволяет вести разработку изолированно: создавать новые функции, исправлять ошибки, не затрагивая основную ветку
6.	Можно ли работать без интернета с Git? 
Да. Git по умолчанию работает локально
